# JWlink

`jwlink` is JWlink 1.9beta 13, built with gcc from the `JWlink.shallow.tar.xz` source archive in
TK Chia's GW-BASIC fork (see `third_party/gwbasic/UPSTREAM`), by that fork's own Makefile rule.
It links GW-BASIC's 39 modules into `GWBASIC.EXE` and writes the map the translator reads.
