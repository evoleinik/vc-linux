# The browser build on phones, and loading programs on first use

**Type:** Decision doc
**Status:** decided, not built
**Date:** 2026-10-01

## Goal

Eugene, 2026-10-01: "I think we'll need to adapt it to mobile browser/input more too. now it's
perfect on desktop". Also, Rogue takes the page from 1.6 MB to 2.9 MB compressed, and VZ Editor,
COMMAND.COM and Maximus will add more. That is slow on a phone network.

## Criteria

1. Every key VC needs is reachable on a phone: F-keys, arrows, Esc, Tab, Ins, Enter, Ctrl, Alt.
2. The screen stays as readable as it is now.
3. The first visit stays fast on a phone network.
4. The desktop page does not change.

## Options shown to Eugene (inline sketch, 2026-10-01)

| Option | Strongest objection | Fails when |
|---|---|---|
| A. Landscape key strip, plus a portrait key pad under a scaled-down screen. | Two layouts to build and test. | The scaled portrait screen is too small to read. |
| B. Landscape only, with a "rotate your phone" screen in portrait. | Portrait users get nothing. | Anyone holds the phone upright. |
| C. Change the sketch first. | Delay. | Never. |

And for page size: load each program's translated code the first time it runs, or keep one
bundle that every visitor downloads whole.

## Answers

1. Eugene, 2026-10-01: "pertrait only. and don't make the screen tiny, why. just keep it as is,
   now the size is right". So: portrait only. The screen keeps exactly its current size and fit,
   and the key pad goes under it. Landscape and desktop stay as they are.
2. Eugene, 2026-10-01: yes, load each program on first use.

## Decision — 2026-10-01

- In portrait on a touch device, a key pad sits under the unchanged screen: F1 to F10, the
  arrows, Esc, Tab, Ins, Enter, sticky Ctrl, Alt and Shift, and a button that opens the phone's
  keyboard. Taps act as mouse clicks, so VC's own key bar works too.
- VC loads first. GW-BASIC, bootLogo, Rogue and later programs download their translated code the
  first time DOS EXEC runs them.
- Order: after VZ Editor and Rogue merge, since all three change the web build.
