# JWasm

`jwasm` is JWasm built from https://github.com/Baron-von-Riedesel/JWasm at commit
`a7c6e70a63cf364b05e44decafc338b4915a8bb0`, the same commit ddanila/vc vendors:

    make -f GccUnix.mak "extra_c_flags=-DNDEBUG -O2 -U_FORTIFY_SOURCE -D_FORTIFY_SOURCE=0"

It is built without `_FORTIFY_SOURCE` because the fortified binary aborts with "buffer overflow
detected" while writing the listing for `VC.ASM`. The assembled `VC.COM` is identical either way.
JWasm is under the Sybase Open Watcom Public License 1.0.

## Kermit's separate assembler

`tools/build_kermit_jwasm.py` builds `build/kermit-toolchain/jwasm` from the
same pinned commit and `kermit.patch`. The original `jwasm` above is unchanged.
`jwasm-a7c6e70.tar.gz` is a `git archive` of that commit, obtained from the local
tools cache and compressed with `gzip -n` (no network). SHA-256:
`d7b5d9bd24ab65fd448fb4d8082551c8ab750ba81896d85ee7de2003a162a7f6`.
The archive contains the upstream license at `Html/License.html`. The tool
build pins `SOURCE_DATE_EPOCH` and normalizes only its own staged CRLF files
before applying the portable diff. Kermit's source files are never normalized.

Kermit 3.15 uses `-Zm -Cu -Dno_network -Sg -Sa -Sl`, plus a forced options
include (`tools/kermit-options.inc`). The exceptions are explicit:

- `OPTION NOKEYWORD:<FS GS>` permits the ASCII control-code names in
  `msgibm.asm:194`, before 386 segment registers existed.
- `-Cu` makes all pure-assembly public and external names case-insensitive;
  Kermit declares `l5cp866` public but another module requests `L5cp866`.
- The `-Zm` fix accepts MASM's destination-width truncation of immediate
  constants in 16-bit code: `mov fill,0ffffh` (`msgibm.asm:4886`) stores FFh,
  and the 75-baud PIT expressions (`msxibm.asm:5010,5026`) wrap at 16 bits.
  Explicitly typed operands, relocations, and 32/64-bit code are not relaxed.
- New `-Sl` keeps `.XLIST` and `.SALL` from hiding source/macro listing rows.
  It changes listing visibility only; all instructions retain their original
  assembler-generated bytes and source text.
- JWasm's data listing writer reuses its small OMF buffer across STRUC `?`
  holes; it can print stale heap bytes. `repair_data_listing()` in
  `tools/build_kermit.py` replaces only data byte columns with exact pre-link
  OMF bytes (zero placeholders for uninitialized holes). Instructions and all
  source text stay untouched. Link-time initializer/byte checks remain active.

JWlink uses `nofarcalls` so it cannot replace a listed far CALL with PUSH CS
and a near CALL. The assembler's own same-segment far-call expansion is
instead normalized and individually checked by the linked-listing front end.
