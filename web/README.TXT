Volkov Commander in your browser.

This is the real Volkov Commander 4.99 file manager.
Its 8086 assembly was machine-translated to WebAssembly.
It is not an emulator.

H: is your playground. These files live only in memory.
Reload the page to undo every change and start again.
There is no shell or external editor. The cd command works.
Type GWBASIC to start BASIC. Try PRINT 2+2, then SYSTEM to return.
Type BOOTLOGO for turtle graphics, or press Enter on BOOTLOGO.COM.
Try REPEAT 36 [FD 60 RT 170]. QUIT, then Enter, returns to VC.
BOOTLOGO.TXT has commands and three drawings to type, including a flower.
Type ROGUE, or open GAMES and press Enter on ROGUE.EXE, for Rogue 5.4.4.
You are @. Move with h (left), j (down), k (up), l (right); y/u/b/n
move diagonally. ? shows help. Q then y quits and returns to VC.
S then y saves in the current directory; ROGUE there restores the game.
Saves and scores disappear when the page is reloaded, like all H: files.
The Linux version manages real files: github.com/evoleinik/vc-linux

Keys to try:
  F3          View the selected file. Esc closes the viewer.
  F5          Copy to the other panel.
  F6          Rename or move.
  F7          Make a directory.
  F8          Delete the selected files.
  Ctrl-[      Put the left panel's path on the command line.
  Ctrl-]      Put the right panel's path on the command line.
  Ctrl-I      Put selected file names on the command line.
  Ctrl-H      Show or hide hidden files.
  Ctrl-L      Toggle the information panel.
  Ctrl-Q      Toggle quick view.
  Alt-letter  Find a name by typing its first letters.
  Alt-F10     Open the directory tree.
  Tab         Switch panels.
  F10         Quit.

HISTORY.TXT tells VC's story. SRC holds its assembly sources.
GAMES holds twelve of David Ahl's public-domain BASIC Computer Games.
SPIRAL.BAS is our own short SCREEN 1 / DRAW graphics demonstration.
Open GAMES, select a .BAS file and press Enter to play.
Use UPPER CASE for answers such as YES and NO.
Ctrl+Pause or Ctrl+Shift+B stops a game; SYSTEM returns to VC.
BEEP, SOUND and PLAY use a square-wave PC speaker after a key press.
